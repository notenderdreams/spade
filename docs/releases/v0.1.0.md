Spade's first release saves, manages, and runs reusable command shortcuts through the `spd` CLI.

- Save commands with named or positional template arguments and inline defaults.
- Organize scripts into sequential chains and pipelines, with stop-on-error support.
- Save working directories per script or override them when running scripts and chains.
- Run commands in the background, list or stop processes, attach to their logs, and clean logs.
- Import and export scripts as `.spade` JSON files.
- Back up local script files and use the saved copy when the original is unavailable.
- Complete commands and flags in Bash, Zsh, and Fish.

Download the archive for your operating system and CPU from the assets below. Each archive includes the `spd` executable and documentation. Verify it against `spade_0.1.0_checksums.txt`, extract it, and put `spd` on your `PATH`.

Supported platforms: Linux and macOS, each on amd64 (Intel/AMD) and arm64 (including Apple Silicon). Windows is not supported in v0.1.0 because background process management requires Unix process groups.

Run `spd --version` to verify the installation. See the included README for usage and installation details.
