Spade v0.1.1 adds Homebrew installation and automated tap publishing.

```sh
brew install notenderdreams/tap/spade
spd --version
```

- Installs the prebuilt binary for macOS or Linux on Intel/AMD64 or ARM64, with no Go compiler required.
- Installs Bash, Zsh, and Fish completions automatically.
- Generates `spade.rb` from the final release checksums, attaches it to this release, and publishes the same file to `notenderdreams/homebrew-tap` through GitHub Actions.
- Ad-hoc signs and verifies both macOS architectures before creating archives and SHA-256 checksums. These signatures do not provide Developer ID trust or notarization.

Direct downloads remain available below. Choose the archive for your platform, verify it against `spade_0.1.1_checksums.txt`, and place the `spd` executable on your `PATH`.

Windows remains unsupported in this release.
